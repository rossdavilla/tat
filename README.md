# TAT Images

Picture cards for a Thematic Apperception Test demonstration — ambiguous scenes that a viewer is
asked to tell a story about.

**Live:** https://rossdavilla.github.io/tat/TATimage1.png

## What's in here

```
TATimage1.png
TATimage2.png
TATimage3.png
```

This repository is an image host, not an app: the cards are linked directly, one per URL, so they
can be projected or dropped into a slide. `index.html` is intentionally empty — there is no
landing page. Adding a card means adding `TATimage<N>.png`.
